`analysis/`; everything else is model output (gzipped JSON, readable with `gzip.open`).

## Record format

Labelled OpinionQA and PersonaMem records share one schema:

```
respondent, question          OpinionQA: row of data/opinionqa/{test,respondents}.csv and question column
prompt                        persona + axioms prompt (also the DPO prompt)
response_types                setup of each response slot
responses                     model outputs
correctness                   1 if the selected option is the respondent's answer
grounding_scores              judge grounding score rescaled to [0, 1]
contradiction_labels          per axiom: A supports / B unrelated / C contradicts
contradiction_rate, rewards   rho and F = g * (1 - rho); a response is faithful when F == 1
```

## Notes

- **Repeated runs** are repeated generations from the same checkpoint, so the +/- values in the paper
  reflect inference variance, not training seeds. PersonaMem `curriculum_run0` and `curriculum_run2`
  are identical.
- **LLaMA-70B correctness** was re-scored from the stored generations: the original labelling run
  saved the responses as parsed dicts and scored every answer as wrong. F is as originally judged.
- **70B models.** `llama-3.3-70b-instruct` is the instruct model and `deepseek-r1-distill-llama-70b` its reasoning-distilled
  counterpart (paper Sec. 4.2); the exact checkpoints were not recorded with the outputs.
